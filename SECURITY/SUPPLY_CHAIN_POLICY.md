# Supply Chain / DevSecOps Policy
Mandatory before production promotion: verified origin and maintainer, pinned version+digest, license (including AGPL implications), direct and transitive dependency review, vulnerability/advisory checks, SBOM SPDX or CycloneDX where feasible, build/install provenance (SLSA-oriented), security posture (OpenSSF Scorecard as signal, not final grade), permission and network least-privilege, credential isolation, malicious-update detection, reproducible rollback and audit. Detect auto-update behaviors and disable uncontrolled changes. Public Git: no tokens, host secrets, paid credentials, private project documents, runtime private logs. No `curl | bash` for unknown scripts without inspect/signature verification.
